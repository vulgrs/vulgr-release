# Vulgr releases

Installers for [Vulgr](https://vulgr.tech), the open-source terminal for AI coding agents.

Download the latest version from **[Releases](https://github.com/vulgrs/vulgr-release/releases)**, or from [vulgr.tech](https://vulgr.tech), which picks the right file for your computer:

- `Vulgr-<version>-arm64.dmg`: macOS, Apple Silicon
- `Vulgr-<version>-x64.dmg`: macOS, Intel
- `Vulgr-Setup-<version>.exe`: Windows
- `Vulgr-<version>-x86_64.AppImage`: Linux (`chmod +x` it, then run it)

macOS builds are signed with a Developer ID certificate and notarized by Apple.
The app checks this repository for updates on its own.
